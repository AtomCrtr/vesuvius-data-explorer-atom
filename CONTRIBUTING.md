# Contributing

Bug reports, documentation improvements, bounded-memory readers and reproducible geometry diagnostics are welcome.

1. Open an issue with an exact reproducible scenario and expected vs actual behavior.
2. Use only appropriately licensed data. Never commit CT volumes, credential files or restricted datasets.
3. Add tests for new logic (`pytest -q`).
4. Distinguish exploratory metrics from scientifically validated measurements.

This project is independent of the Vesuvius Challenge; follow their official contribution channels for upstream work.
